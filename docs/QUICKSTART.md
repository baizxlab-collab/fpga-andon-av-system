# 快速运行

## 环境

- 安路 EG4S20BG256 开发板 ×4，依工程角色标注 A/B/C/D。
- 7 英寸电容触摸屏连接 B；A、C 分别连接 HDMI 显示设备；OV5640 连接 A。
- 三张 FAT32 TF 卡；D 的当前采集与分析演示不需要 TF 卡。
- Windows 下使用 Anlogic TD 6.2.168116（TD 6.2.1），下载器及驱动按开发板说明安装。

## 运行步骤

1. 按 [WIRING.md](WIRING.md) 断电完成板间接线，保留原屏幕与摄像头连接。
2. 分别将 `media/TF_A/`、`media/TF_B/`、`media/TF_C/` 的内容放入对应 TF 卡根目录。目录名本身不要再套一层。
3. 给 D 下载 `firmware/board_d_sensors.bit`；C 下载 `board_c_dual_display_rpc.bit`；B 下载 `board_b_media_touch.bit`；A 下载 `board_a_dual_display_rpc.bit`。
4. 各板就绪后复位 A，等待实际素材加载完成，进入小屏首页选择功能。
5. 需要断电保持程序时，按所用开发板对应流程执行 Program Flash；临时 SRAM 下载仅保持到断电。

## 主要操作

| 操作 | 效果 |
|---|---|
| 小屏选择照片/工厂亮点/文字宣传 | 主屏显示对应图片、字幕及该页配乐 |
| A KEY2 短按松开 | 图片类页面下一张；相册中翻下一视图 |
| A KEY3 短按松开 | 切换当前图片类页面的自动轮播或相册自动翻页 |
| 小屏视频播放 | C 从采集画面切到视频，片尾自动进入下一可用片段 |
| 小屏暂停/离开视频 | C 恢复 D 实时采集画面；再次播放从所选视频开头开始 |
| 小屏控制中心 | 调整音量、亮度、对比度并选择远程运行状态 |
| A SW1/SW2/SW3 | 实体缺料/设备故障/急停；恢复拨码后解除对应实体告警 |
| D SW1/SW2/SW3 | 演示时域、频域、空间耦合异常，故障经 C 联动到 A |
| B 正常工作或 D KEY4 短按松开 | 确认 D 锁存故障并重新布防；不解除 A 仍保持的实体告警 |

更多细节见 [演示路线](DEMO.md)。
