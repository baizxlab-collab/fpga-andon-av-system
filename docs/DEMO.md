# 推荐演示路线

从“展示—交互—预警—采集联动”依次展开，评审可沿此路线快速了解作品。

| 顺序 | 操作 | 重点展示 |
|---|---|---|
| 1 | 上电进入封面，等待加载完成 | 纯硬件启动、汽车主题加载动画及真实处理进度 |
| 2 | 小屏进入工厂亮点 | 制造主题图片、对应介绍字幕、配乐及随 PCM 跳动的音频柱 |
| 3 | A KEY2 切换，KEY3 切换自动模式 | 实体控制、自动轮播和四种图片转场 |
| 4 | 返回首页进入文字宣传 | 四组独立宣传素材、对应文字与专属配乐、动态声画可视化 |
| 5 | 进入照片，对比不同分辨率素材 | 原图尺寸显示，统一 640×480 画布与硬件双线性缩放 |
| 6 | 进入智造之旅并翻页 | 封面、三组跨页、封底；触屏手动翻页与 A 自动翻页 |
| 7 | 进入实时监控 | A 的摄像头预览持续更新，主题化文字与状态辅助展示 |
| 8 | 进入视频，播放并等待片尾 | C 独立视频解码、声画输出、四片循环；暂停后回到采集画面 |
| 9 | 打开控制中心调音量 | 同一音量控件同时影响 A 的告警/音乐与 C 视频；亮度、对比度实时调节 |
| 10 | 依次拨动 A SW1/SW2/SW3 | 缺料、设备故障、急停声画抢占；实体拨码保持时，触屏无法解除 |
| 11 | A 拨码恢复正常，触发 D 开关异常 | 五路工况实时分析、三类异常、首次异常分数锁存，经 C 联动 A 设备故障页 |
| 12 | B 选择正常工作或短按 D KEY4 | 确认 D 故障、重新布防；再次异常可以再次触发 |

## C 本地操作

| 按键 | 视频中 | 采集画面中 |
|---|---|---|
| KEY1 | 复位 C | 复位 C |
| KEY2 | 下一可用片段 | 下一通道 |
| KEY3 | 返回采集 | 冻结/解冻 |
| KEY4 | 返回采集 | 进入视频 |

## 展示口径

系统依靠 FPGA 并行数据通路完成媒体读取、显示合成与预警控制，正常操作无需上位机参与。D 的数据源为片上模拟工业工况，便于在比赛现场重复演示时域冲击、高频变化和双振动耦合异常。A 的告警可同时呈现摄像头画面、中文原因、首次异常分数和声音提示，体现多板协同的应用价值。
