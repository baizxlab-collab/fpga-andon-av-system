# 仓库组织参考

采用 FPGA 项目常见的“工程入口 / RTL / 约束 / 构建脚本 / 文档 / 固件”组织方式，并为四板协作补充接线、角色、素材及评审演示路线。以下项目仅作为目录和说明结构参考，未复制其实现代码或许可证：

- [gpanders/fpga-design-template](https://github.com/gpanders/fpga-design-template)：工程设置与可复现构建组织。
- [enjoy-digital/litex](https://github.com/enjoy-digital/litex)：功能介绍、文档入口和贡献说明组织。

源码保护采用本机 TD 6.2.1 自带 Encrypt Tool，参考官方 SWUG113《Encrypt Tool User Guide》。
