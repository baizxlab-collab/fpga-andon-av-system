# 程序画面预览

下载仓库后，双击 [打开图集.html](gallery/打开图集.html) 可按功能筛选并放大查看；GitHub 网页可直接打开下列总览及对应目录内的 PNG。

| 功能 | 数量 | 入口 |
|---|---|---|
| 照片 | 4 张 | [照片总览](gallery/总览_照片.png) |
| 文字宣传 | 4 张 | [宣传总览](gallery/总览_文字宣传.png) |
| 工厂亮点 | 4 张 | [工厂亮点总览](gallery/总览_工厂亮点.png) |
| 智造之旅 | 5 个视图＋1 个翻页中间态 | [相册总览](gallery/总览_智造之旅.png) |
| 视频 | 四个视频各自第 0 帧 | [视频首帧](gallery/总览_视频首帧.png) |
| 小屏 | 13 个功能/相册视图 | [小屏总览](gallery/总览_小屏.png) |

图集共 35 张完整显示画面，附原生书页底图及纯解码视频首帧。画面由对应 RTL 与实际素材生成，用于 PC 端查看；音频可视化、字幕和诊断状态为选定时刻的仿真输入。
