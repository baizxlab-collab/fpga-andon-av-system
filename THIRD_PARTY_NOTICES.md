# 第三方组件与素材说明

本作品在原创系统集成、控制、显示、预警与多板协同逻辑中使用了部分厂商 IP 和第三方基础模块。加密交付保留原始署名，不改变各组件的权利归属。

## 主要来源

| 内容 | 原始来源与说明 |
|---|---|
| JPEG 解码基础模块 | Ultra-Embedded.com，Copyright 2020，Apache License 2.0；当前工程含适配与共享 IDCT 等集成调整，以现有实现为准 |
| PLL、FIFO、SDRAM 等厂商基础代码 | Anlogic Inc. 及开发板配套资料；遵循原有厂商条款 |
| OV5640 采集及 SCCB/I²C 基础模块 | 正点原子配套参考模块；保留原始署名及权利声明 |
| 网口相关模块 | 原有工程中保留的厂商 TEMAC 与适配文件；发布副本不新增启用功能 |
| 图片、视频、字体、UI 与音频素材 | 用于当前工业主题作品演示，分别归原素材、字体和组件权利人；不作为独立通用素材授权包 |
